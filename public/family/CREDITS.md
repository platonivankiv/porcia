# Иллюстрации семьи Porcia

`man.webp`, `woman.webp`, `child.webp` — утверждённые AI-иллюстрации A/v3, созданные 23 ноября 2026 года инструментом image_gen на основе предоставленных владельцем визуальных референсов. Прозрачные WebP перенесены без изменения из изолированного прототипа.

Иллюстрации используются в пустом состоянии, карточках целей и выборе половой категории для формулы. В POR-DESIGN-006 добавлен ручной выбор декоративного аватара участника из этой коллекции. Это не изображение реальной внешности. Персонаж не назначается по имени, параметрам формулы, возрасту или порядку карточки. Без ручного выбора используется нейтральная монограмма. В профиле хранится только необязательный avatarId (`man`, `woman`, `child`), без изображения; версия хранения остаётся 2.

Полные исходные промпты: [PROVENANCE.json](./PROVENANCE.json).
