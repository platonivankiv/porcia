# POR-DESIGN-003 — семейные профили A/v3

Исходная точка: `7c106fc`. Источник: соседний изолированный `porcia-design-001-prototype/v3.html`, `v2.css`, `v3.css`, снимки семейных профилей и редактора A/v3. Коммит в рамках задачи не создаётся.

## Граница изменения

Только `/family`: оформление списка, карточек, формы и вывод существующего расчёта. Используются токены POR-DESIGN-002, Oswald 700/Manrope, контуры: карточки/панели 3 px, кнопки 2 px, поля и группы продуктов 1.5 px, как в утверждённом A/v3. CSS записан по одному свойству на строку и ограничен семейным экраном; оформление POR-009 и рецептов сохраняется.

У реальных участников — нейтральная монограмма. Цвета чередуются по карточкам, без демографического смысла. Утверждённые персонажи A/v3 используются декоративной группой отдельно от участников, в пустом состоянии и редакторе. Никакого назначения внешности по имени, возрасту или половой категории; выбора персонажа и нового поля модели нет. Иллюстрации и AI-происхождение находятся в `public/family/`.

Форма остаётся одним документом: основные данные, параметры расчёта, ограничения, предпочтения. В desktop-редакторе существующий живой расчёт вынесен в правую колонку; на небольшом экране колонки складываются в порядке документа. Продукты выбираются подписанными native checkbox в раскрываемых группах. Имена FormData и значения сохранены. Текстовые записи доступны отдельно, сохранённые значения раскрываются при открытии формы.

Модели, storage, валидация и формулы не меняются. На компактной карточке пояснения полного расчёта раскрываются через details; причины недоступности, частичные значения и предупреждения остаются видимыми. Существуют исходные состояния загрузки, ошибок чтения/записи, подтверждения сброса и отмены.

## Проверки

Границы тестирования: существующие render, FormData, calculation и storage; браузерные сценарии сохранения, редактирования, отмены, ошибок и живого пересчёта. Для чекбоксов и нейтральной карточки выполнены red → green проверки рендера.

### Результат

- `npm test`: 240 тестов в 12 файлах. `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check` — успешно.
- Изолированный Chrome: обязательное имя и фокус ошибки, сохранение неполного профиля, живые полные/частичные/невалидные результаты, checkbox клавишей Space, текстовые записи, сохранение и восстановление после reload, отмена без изменения записи. Ошибка записи сохраняет ввод; повреждённая запись остаётся нетронутой и показывает существующий интерфейс восстановления.
- Пустой список, карточки, редактор, длинное имя и ошибка хранения проверены на 320/390/768/1440 px: горизонтального переполнения нет. Подтверждены hover, focus-visible 3 px и reduced motion. Все проверки выполнялись с вымышленными данными в отдельном временном профиле браузера.
- Контраст основного и вторичного текста соответствует WCAG AA; вторичный текст на фоне A/v3 имеет 6.98:1. Общий marketing-checker не прошёл: он требует полноэкранный hero, верхнюю навигацию и секции фиксированной высоты, что противоречит утверждённому продуктовому экрану; его порог 7:1 для body text также выше AA. Применимые проверки overflow/collisions/focus/font-load/reduced-motion прошли. Найденные им недостаточный `sizes` для иллюстраций и отсутствие hover у credits исправлены; палитра A/v3 сохранена.
- Снимки production-приложения и сравнение с A/v3 находятся вне репозитория: `porcia-design-001-prototype/previews/POR-DESIGN-003*`. Участники на снимках имеют явную пометку «демо».
- Read-only review Standards и Spec: открытых замечаний нет после повторной проверки. Исправлен порядок CSS-правил карточной кнопки. Толщины полей уточнены по исходному `v3.css`: 1.5 px; это не изменение утверждённого дизайна.
- Файлы моделей, формул, storage, validation, пакетный манифест/lockfile и стили каталога/рецептов не изменены. SHA-256 всех трёх иллюстраций совпадают с A/v3. Коммит не создавался.


## Уточнение выбора пола

По запросу владельца список половой категории заменён двумя native radio-карточками «Мужской» и «Женский» с утверждёнными иллюстрациями, лавандовым/зелёным фоном, увеличением персонажа при hover и контуром выбранной карточки. Клавиатурные стрелки работают нативно; reduced motion отключает увеличение. Кнопка «Снять выбор» сохраняет возможность оставить расчётную категорию незаполненной и удаляет устаревшие результаты из живого preview. Это выбор существующего `calculation.sexForEquation`, а не аватара; имена/значения FormData и формат storage сохраняются.
