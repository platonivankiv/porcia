# POR-DESIGN-005 — визуальная доработка каталога и рецепта

Утверждён владельцем изолированный прототип `porcia-design-001-prototype/por-design-005/`. Baseline: `832fadd`. Визуальный источник: статические экраны, `refinement.css`, снимки и `review.html`. Прототипный JS и snapshot CSS целиком в приложение не переносятся. Коммит не создаётся.

## Согласованная граница

- Каталог: компактная шапка без принудительного переноса, плотные карточки, полные названия, прежние три изображения и метаданные. Боковая/мобильная навигация не меняется.
- Рецепт: низкий горизонтальный hero на desktop, вертикальный на mobile. Метки реальных общего и активного времён; «подготовка» не вычисляется вычитанием. КБЖУ на одну базовую порцию в компактной полосе; на mobile энергия в отдельной строке, БЖУ в трёх колонках.
- Общий счётчик порций перед колонками ингредиентов/шагов, в отдельной жёлтой полосе. Это общий объём, без выбора участников или автоматического распределения. Суммарная энергия показывает только текущий валидный результат.
- Состояния продуктов, единицы, исходные количества и известный/неизвестный выход сохраняются. Шаги и safety не сокращаются. Аллергены видны вне details. Пояснение о времени и базовом объёме находится в методике; при ошибке расчёта остаётся в блоке ошибки, чтобы не терять оговорку.
- POR-009 остаётся настоящим независимым закрытым блоком, в отличие от неподключённого прототипного placeholder. Существующий FamilyRecipePortions, черновики, коэффициенты и предупреждения не переписываются.
- Формулы, парсеры, модели, каталог/рецепты, изображения/их provenance, семейные профили, localStorage и зависимости не меняются. Поиск, фильтры, рационы, планировщик, баннер с аватарами и новые пункты навигации не добавляются.

CSS остаётся в существующих файлах каталога/рецепта, одно свойство на строку. Меняются текущие правила и адаптивные ветки; отдельный слой prototype overrides не добавляется. Реорганизация общей системы и SCSS — POR-STYLE-001.

## Проверки и review

Границы тестирования: существующие render, calculations и parsers; production browser для счётчика, пустых/невалидных значений, POR009 и адаптивности. Render-проверки сначала падают на новом расположении счётчика, подписи базовой порции и временных метках, затем проходят. Отдельно проверяется сохранение временной оговорки при отсутствующих данных.

Обязательные команды: npm test, npm run typecheck, npm run lint, npm run build, git diff --check. Браузер: каталог и три рецепта на320/390/768/1440, источники, дробные/ошибочные порции, safety/allergens, настоящий POR009, keyboard/focus/hover/reduced motion. Отсутствующие данные/изображение/время — через изолированные SSR fixtures существующего компонента, без изменения production-каталога.

Независимые read-only Standards и Spec review: `git diff 832fadd` и все новые файлы. После проверки замечания исправляются и перепроверяются.

## Результат реализации

- `npm test`: 243 теста, 12 файлов — успешно. `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check` — успешно.
- Production-браузер: каталог и все три рецепта на 320, 390, 768 и 1440 px. 40 проверок геометрии, включая раскрытые источники и POR-009; горизонтального переполнения нет. Все изображения загружены, Oswald 700 и границы 3 px применены.
- Проверены целые и дробные порции (`1,25`), пустой ввод, ноль, нечисловой ввод и восстановление после ошибки; неверные значения не оставляют устаревших результатов. Проверены единицы, аллергены, предупреждение 74 °C и источники.
- POR-009 проверен через настоящий временный профиль, созданный формой в отдельном браузерном профиле: коэффициенты, ноль, ошибка, независимость от общего счётчика и сохранение черновика после закрытия. Данные реального пользователя не использовались.
- Отдельные SSR fixtures существующих компонентов: отсутствие продуктовых данных, изображения и времени; 8 проверок геометрии. Эти состояния не добавлены в production-каталог.
- Клавиатура открывает оба details; ссылка назад и карточки работают. Проверены focus-visible, hover и reduced motion. Минимальный измеренный контраст видимого текста — 6,86:1; нарушений порогов WCAG AA в проверенных экранах не найдено. JS-исключений нет.
- Независимые read-only Standards и Spec review завершены без открытых замечаний. Четыре необязательных замечания о перекрывающихся CSS-декларациях исправлены и перепроверены.
- Изменения ограничены двумя CSS-файлами, тремя компонентами представления, render-тестами и этим документом. Данные, расчётные модули, семейные компоненты, навигация, изображения, хранение и зависимости не изменены. Коммит не создан.
