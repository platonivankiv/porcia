# Porcia — концепция продукта

Статус: обновлено по POR-010 23 ноября 2026 года. Это направление продукта, а не объявление реализации завершённой.

«Порция» помогает семье питаться вкусной обычной домашней едой, учитывать индивидуальные цели и меньше времени тратить на выбор блюд, готовку и покупки. Основной сценарий: семья → автоматические дневные КБЖУ → каталог карточек готовых рационов на несколько дней → выбор конкретного рациона → автоматический расчёт индивидуальных количеств продуктов → готовый план приготовления и распределения еды. Общий список покупок появится в дальнейшем.

Готовый рацион — шаблон с конкретными блюдами. Его карточка описывает меню на несколько дней, ориентировочное общее время приготовления и особенности меню. Персонализированный план семьи содержит выбранное меню и рассчитанные количества для участников; пользователь может менять количества, заменять блюда или создавать собственный рацион.

## Обязательные принципы

- Вкус, простые действия и минимальное активное время — критерии качества рецепта. Масло, специи и соусы допустимы; используемые пищевые ингредиенты входят в состав и расчёт.
- Выбранный рацион сохраняет набор блюд: приложение не заменяет их без подтверждения пользователя. Если адаптация количеств не позволяет точно попасть в КБЖУ, показываются отклонения и варианты изменений для подтверждения. Строгие ограничения при этом не нарушаются.
- Индивидуальные количества рассчитываются автоматически. Пользователь видит граммовки продуктов с указанием состояния; базовые порции остаются внутренним механизмом, а не коэффициентами для ввода. Ингредиенты смешанного компонента масштабируются совместно.
- Общая еда сочетается с индивидуальными количествами отдельно приготовленных компонентов.
- Рекомендации помогают выбирать еду; пользователь сохраняет контроль над планом. Ручная правка не вызывает скрытого перераспределения остальных блюд.
- Перекусы, сладости, готовые продукты и калорийные напитки — полноценная часть рациона. Число приёмов пищи и доля энергии для сладостей не задаются универсальным правилом.
- Снижение веса, поддержание, набор мышечной массы и рекомпозиция поддерживаются как разные цели. Суточные ориентиры автоматически обновляются из параметров профиля; в текущем сценарии POR-008 ручной корректировки КБЖУ нет.
- Строгие ограничения и безопасное хранение важнее оптимизации КБЖУ и сокращения готовок. Сладость продукта сама по себе не является основанием запрета.
- Неизвестные пищевые данные, сроки хранения и выход не подменяются выдуманными значениями. Удобные инструкции не должны обещать безопасность только по времени приготовления.
